# Outside CONUS

The NHF can be built for Alaska, Hawaii, and Puerto Rico/Virgin Islands domain using a reference that matches the schema of the SuperCONUS reference. A new reference can be interchanged as long as the schema matches.

The process is the same and uses configs set for OCONUS domains. There are some minor deviations:
- Alaska has no lakes_polygons layer
- Level pool is used for all reservoir DA in OCONUS
- Some divide attributes are missing

Network quality suffers from NHD quality issues.
